## Phase 1 — Localized Poisson estimators (Aug 31–Sep 6)

New module `Utils/localized_estimators.py`, drop-in compatible with `PoissonMCEstimator`
interface (`forward(x_query, x_land, g_land) -> (v_hat, gradv_hat)`, differentiable):

- [ ] **L1 Compact-support kernel**: `G_ε(r)·w(r/R)` with Wendland C² cutoff
      (screened-Poisson interpretation); strictly local interactions, O(B·M_local)
- [ ] **L2 kNN quadrature**: per-query k nearest landmarks among M sampled,
      distance reweighting
- [ ] Verify `BC_loss` / `D_loss` work unchanged with both estimators
- [ ] Toy validation: field error maps (localized vs global Green);
      wall-clock/memory scaling vs d ∈ {2…784}, M, B

**Theory deliverables (paper §4):**
- Error decomposition: quadrature error + truncation bias + ε-regularization bias
- Consistency as R→∞ / k→M (recover global estimator)
- Cost–locality trade-off analysis; conditions preserving flux/bulk terms
